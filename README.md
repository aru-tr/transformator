# Трансформатор зертханасы

Қазақ тіліндегі интерактивті зертхана: орам санын 1, 2, 4 етіп өзгерту, идеал трансформатор кернеулерін салыстыру, бақылау кестесі мен CSV экспорты және қателікті қадамдап есептеу.

## Іске қосу

Қосымша тәуелділіктер жоқ. `index.html` файлын браузерде ашыңыз немесе репозиторий ішінде `python3 -m http.server 8000` орындаңыз.

## GitHub Pages

Репозиторийдің Settings → Pages → Source бөлімінде **GitHub Actions** таңдаңыз. `main` тармағына push жасалғанда `.github/workflows/pages.yml` сайтты жариялайды. Күтілетін мекенжай: https://aru-tr.github.io/transformator/ (жариялау сәтті аяқталғаннан кейін).

## Модель шектеулері

Бұл PhET көшірмесі емес. Ортақ өзекшесі бар идеал трансформатор моделі қолданылады: U₂/U₁ = N₂/N₁. Шығындар, қанығу, жүктеме және магнит ағынының шашырауы есептелмейді. Бірінші орамдағы кернеу тұрақты кезде N₁ артса U₂ кемиді; мұны PhET-тегі өзекшесіз катушкалар бақылауымен шатастырмаңыз. Кернеулер әсерлік мәндер, анимация баяулатылған. Қателік калькуляторының бастапқы деректері — үлгі; тәжірибеден алынған өлшеулер емес. Екінші тәжірибедегі U₁ бөлек өлшенеді деп қабылданады.
